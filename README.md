# Пакеты AmneziaWG для роутера Archer-AX55 с прошивкой OpenWrt
Скрипт установки 
```sh
wget -O - https://raw.githubusercontent.com/NuclearTruck/awg-openwrt/refs/heads/master/install-awg.sh | sh
```
Сразу с пакетами ру локализации
```sh
wget -O - https://raw.githubusercontent.com/NuclearTruck/awg-openwrt/refs/heads/master/install-awg.sh | sh -s -- --ru
```
Без пакетов ру локализиции
```sh
wget -O - https://raw.githubusercontent.com/NuclearTruck/awg-openwrt/refs/heads/master/install-awg.sh | sh -s -- --no-ru
```
